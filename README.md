# MediPulse

A medicine reminder app for patients in India, in English, Hindi and Kannada. MediPulse is Phase 1 of DocAssist, a planned doctor–patient care platform.

- `CLAUDE.md`: context and rules for Claude Code (and for humans)
- `docs/tech-spec.md`: the technical spec
- `docs/product-context.md`: who it's for and the product rules
- `docs/backlog.md`: what to build next
- `design/`: Stitch screens, design system and Tailwind tokens
